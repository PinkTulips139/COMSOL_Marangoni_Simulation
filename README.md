# COMSOL 中毛细效应与浓度驱动马兰戈尼效应的自由液面数值研究

## 1. 项目概述

本项目使用 COMSOL Multiphysics 建立二维气液两相模型，研究水热反应条件下自由液面的瞬态演化，并比较毛细效应与浓度驱动马兰戈尼效应对液面形变的相对贡献。

项目来源于氧化镓纳米线水热生长实验。实验中，二氧化硅衬底倾斜放置于特氟龙内衬中，生长液只浸没衬底的一部分，但在初始液面以上的衬底区域仍观察到纳米线生长。

项目最初希望通过 COMSOL 复现实验现象，估计自由液面的抬升高度，并判断马兰戈尼效应是否能够将液体输运至初始液面以上的衬底区域。

随着模型逐步完善，研究重点由“定量复现实验液面高度”转向“对毛细效应与马兰戈尼效应进行数值分离和量级比较”。

---

## 2. 实验背景

生长液由以下物质配制：

```text
0.1682 g 九水硝酸镓
0.082 g 六亚甲基四胺
120 mL 去离子水
```

反应温度约为：

```text
150 °C
```

二氧化硅衬底边长约为：

```text
15 mm
```

衬底倾斜放置于特氟龙内衬中，初始生长液只浸没衬底的一部分。

模型主要关注以下问题：

- 自由液面是否会沿衬底发生抬升或下降；
- 浓度梯度引起的表面张力梯度会如何影响液面；
- 毛细作用与马兰戈尼作用是否相互协同；
- 两种效应在当前参数条件下相差多少量级；
- 瞬态液面最终是否会趋于稳定。

---

## 3. 建模思路的演变

### 3.1 初始设想：复现实验液面抬升

项目初期假设毛细效应与马兰戈尼效应可能共同推动液面沿衬底上升。

最初希望通过模型回答：

```text
自由液面能够抬升多少？
马兰戈尼效应在总液面抬升中贡献多少？
```

实际实验中观察到的液面变化约为数毫米，但该现象同时受到：

- 壁面润湿；
- 接触角；
- 基准表面张力；
- 重力；
- 浓度梯度；
- 液体流动

等多种机制影响。

因此，仅凭液面最终抬升高度难以直接区分毛细效应与马兰戈尼效应的贡献。

### 3.2 后续发现：两种效应并非简单协同

在当前模型和参数设置下，初步数值结果显示：

- 毛细效应对自由液面形态的影响明显强于马兰戈尼效应；
- 两者的液面形变量可能相差约两个数量级；
- 纯马兰戈尼模型没有产生预期的液面抬升；
- 在当前浓度分布与表面张力关系下，局部液面反而出现下降或下压。

因此，马兰戈尼效应并不一定与毛细效应同方向作用。

马兰戈尼流动的方向取决于界面上的表面张力分布。浓度梯度通过改变表面张力，驱动流体沿界面向较高表面张力区域运动。最终液面是抬升还是下降，还取决于：

- 浓度梯度方向；
- `dσ/dc` 的符号；
- 界面几何；
- 接触角；
- 流场与重力；

### 3.3 最终研究目标：数值分离与量级比较

项目最终不再将“精确复现实验液面高度”作为唯一目标，而是建立两个对照模型：

1. 纯马兰戈尼效应模型；
2. 毛细效应与马兰戈尼效应耦合模型。

通过控制接触角和基准表面张力，比较：

- 两种机制产生的液面形变量；
- 界面形变方向；
- 稳定状态；
- 作用量级；
- 对网格和时间步长的敏感性。

## 4. 模型组成

模型采用二维平面截面，包含液体域、气体域、倾斜衬底和容器壁面。

主要物理场接口包括：

- 层流 `Laminar Flow (spf)`；
- 流体相场 `Phase Field (pf)`；
- 稀物质传递 `Transport of Diluted Species (tds)`；
- 域常微分和微分代数方程 `Domain ODEs and DAEs (dode)`；
- 两相流—相场多物理场耦合；
- 相初始化；
- 瞬态研究。

模型假设温度恒定为 150 °C，不求解温度场，也不显式模拟蒸发、沸腾和气液相变。温度仅通过密度、动力黏度、扩散系数和表面张力等参数影响模型。

---

## 5. 两个对照模型

### 5.1 纯马兰戈尼效应模型

该模型尽量弱化壁面润湿差异和基准毛细压力。

接触角设置为：

```text
SiO2 衬底：90°
Teflon 内壁：90°
顶壁：90°
```

表面张力系数设置为：

```text
sigma = dsigmadc * (c - c0)
```

该模型用于观察浓度偏离初始浓度后产生的表面张力梯度效应。

需要注意，该表达式不包含真实液体的基准表面张力，因此属于机制隔离模型，而不是完整的实际表面张力模型。



```text
当 c = c0 时，sigma = 0
当 c < c0 时，表达式还可能产生负的表面张力系数
因此，该模型的物理含义和数值稳定性仍需进一步检查
```

### 5.2 毛细效应与马兰戈尼效应耦合模型

该模型保留基准表面张力，并使用不同材料边界的接触角。

接触角设置为：

```text
SiO2 衬底：50°
Teflon 内壁：100°
顶壁：90°
```

表面张力系数设置为：

```text
sigma = sigma_ref + dsigmadc * (c - c0)
```

该模型同时包含：

- 基准表面张力产生的毛细压力；
- SiO2 与 Teflon 接触角差异产生的润湿作用；
- 浓度梯度产生的马兰戈尼作用。

## 6. 主要数值困难

COMSOL 是基于有限元方法的多物理场数值仿真平台。

在本项目中，即使几何、物理场接口和耦合关系在概念上保持一致，模型仍可能因为以下数值因素出现不收敛：

- 网格过粗或过细；
- 相场界面厚度与网格不匹配；
- 时间步长过大；
- 初始时间步长不合适；
- 相对容差或绝对容差设置不合适；
- 非线性求解器迭代失败；
- 接触角与表面张力导致强毛细压力；
- 多物理场变量在部分域中未定义；
- 相初始化与瞬态研究之间初始值传递不稳定。

因此，物理设置合理并不等于数值模型必然收敛。

本项目在建模过程中进行了多轮数值对照和消融尝试，包括：

- 调整网格尺寸；
- 调整局部边界分布；
- 修改最大时间步长；
- 修改输出时间间隔；
- 调整求解器容差；
- 对比相场与其他界面追踪思路；
- 尝试使用体积力表示马兰戈尼作用；
- 分别开启或关闭基准表面张力；
- 将接触角统一设置为 90°；
- 分别研究纯马兰戈尼和毛细—马兰戈尼耦合情况；
- 调整稀物质传递接口的作用域。

这些调整并非项目研究目标本身，但对获得可计算、可比较的结果具有决定性影响。

## 7. 移动界面中的浓度变量问题

模型中的表面张力系数依赖浓度变量：

```text
c
```

最初，稀物质传递接口只选择液体域。

但相场法中的气液界面会随时间移动。当液体进入初始定义的气体域时，多物理场接口仍会在移动界面附近访问浓度变量 `c`。

如果气体域不属于稀物质传递接口的作用域，则会出现：

```text
变量 c 未定义的问题
```


一种直接尝试是在气体域中设置：

```text
初始浓度 = 0
扩散系数 = 0
```

但这种方法仍将参数固定在初始几何域上，不能随移动的气液界面自动更新。

因此，需要建立一个能够随相场变量变化的液相—气相指示变量。

---

## 8. 域常微分和微分代数方程解决方案

为解决移动界面中参数无法根据当前相区自动切换的问题，模型增加了：

```text
Domain ODEs and DAEs (dode) 接口
```

该接口作用于所有域，定义辅助变量：

```text
u2
```

方程源项设置为：

```text
u2 - (phipf > 0.2)
```

方程退化为代数约束：

```text
0 = u2 - (phipf > 0.2)
即：u2 = (phipf > 0.2)
```

在当前相场定义中：

```text
液相：phipf ≈ 1
气相：phipf ≈ -1
界面区域：phipf 在 -1 到 1 之间连续变化
```

因此：

```text
当 phipf > 0.2 时，u2 = 1
当 phipf <= 0.2 时，u2 = 0
```

`u2` 作为随时间和空间更新的相区指示变量，可用于：

- 判断当前位置属于液相还是气相；
- 切换扩散系数；
- 控制浓度相关参数；
- 避免参数固定在初始几何域；
- 使传质参数随移动界面同步更新。

该方法是本项目最终能够完成瞬态计算的重要数值处理之一。

## 9. 当前数值结果

### 9.1 纯马兰戈尼效应模型

当前结果显示，在接触角全部设为 90°、不包含基准表面张力的情况下，浓度驱动的马兰戈尼作用没有使液面明显抬升。

在当前参数和浓度分布下，局部液面反而出现下降或下压。

这一结果说明：

- 马兰戈尼效应的方向由表面张力梯度决定；
- 浓度梯度并不必然导致衬底附近液面上升；
- 当前模型中的表面张力方向可能使界面流体远离衬底附近区域；
- 结果还可能受到表面张力表达式、浓度边界条件和扩散系数设置的影响。

### 9.2 毛细效应与马兰戈尼效应耦合模型

加入基准表面张力和材料接触角后，液面形变主要由毛细润湿作用控制。

当前初步比较表明，在本项目参数范围内，毛细效应产生的液面形变量可能比纯马兰戈尼效应大约两个数量级。

该数量级差异属于当前数值结果，不应被视为适用于所有实验条件的普遍结论。

结果仍会受到以下因素影响：

- 接触角；
- 基准表面张力；
- `dσ/dc`；
- 浓度场；
- 衬底位置；
- 网格；
- 时间步长；
- 相场参数。

---

## 10. 当前认识

基于当前模型，可以形成以下阶段性认识：

1. 实验中的液面抬升不应直接全部归因于马兰戈尼效应；
2. 在当前参数下，毛细效应可能是液面抬升的主要贡献来源；
3. 浓度驱动马兰戈尼效应的作用方向并不一定与毛细作用一致；
4. 纯马兰戈尼作用产生的液面形变量明显小于毛细作用；
5. 马兰戈尼效应仍可能影响局部流动、浓度输运和界面形态；
6. 仅凭二维模型不能完整解释液面以上区域的纳米线生长；
7. 模型更适合用于比较机制和量级，而不是直接复现实验中的全部现象。

## 11. 求解器设置经验

### 分离求解器

当前分离求解器采用以下设置：

| 设置项 | 当前设置 |
|---|---|
| 终止技术 | 迭代或容差 |
| 最大迭代次数 | `60` |
| 容差因子 | `0.5` |
| 终止准则 | 解或残差 |
| 残差因子 | `1000` |
| 非线性收敛速率限制 | 不启用 |
| 自适应容差 | 不启用 |

增加最大迭代次数可以为强耦合变量提供更多收敛机会，但迭代次数过高并不能修复错误的物理设置或严重不合理的网格与时间步长。

### 时间步进

瞬态求解器采用隐式向后差分公式：

| 设置项 | 当前设置 |
|---|---|
| 求解器类型 | 隐式 |
| 时间积分方法 | BDF |
| 内部步长 | 自由 |
| 初始步长 | `0.001 s` |
| 最大步长 | 自动 |
| BDF 阶次 | `1–2` |
| 事件容差 | `0.05` |
| 非线性控制器 | 启用 |

较小的初始步长有助于建立稳定的初始气液界面，但会增加前期计算量。最大步长保持自动，使求解器能够根据误差和非线性收敛情况自适应调整。

### 时步存储

本模型选择：

```text
求解器采用的最接近输出时间的步长
```

## 12. 模型局限

本项目存在以下主要局限：

- 使用二维几何代替实际三维反应釜；
- 使用高温水参数近似真实生长液；
- 未显式模拟温度场；
- 未显式模拟蒸发和气液相变；
- 未模拟 HMTA 分解及完整化学反应；
- 将衬底反应简化为边界通量；
- 使用线性表面张力—浓度关系；
- 接触角采用近似值；
- 结果对网格和求解器设置较敏感；
- 两个对照模型的网格精细程度并不完全相同；

因此，本项目的结果应理解为数值机制研究，而不是对真实实验的完整预测。
