# 全局参数与定义节点说明

## 1. 文档说明

本文件记录 COMSOL Multiphysics 模型中的全局参数和“定义”节点设置，用于：

- 统一说明模型中各参数的数值、单位和用途；
- 记录状态变量、积分算子、平均算子和边界坐标系；

## 3. 模型“定义”节点

| 节点名称 | COMSOL 标识 | 当前作用 |
|---|---|---|
| 状态变量 1 | `state1` | 定义状态变量 `ccc` |
| 积分 1 | `intop1` | 对选中域中的变量进行积分 |
| 平均值 1 | `aveF` | 对选中域中的变量进行平均 |
| 边界坐标系 1 | `sys1` | 建立局部边界坐标方向 |
| 视图 1 | `View 1` | 控制几何和结果显示方式 |
