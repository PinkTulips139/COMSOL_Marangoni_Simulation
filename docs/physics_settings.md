# 物理场与多物理场参数设置

## 1. 文档说明

本文件记录 COMSOL Multiphysics 模型中各物理场接口、多物理场耦合、网格和研究步骤的主要设置。

仓库中包含两个模型：

1. **纯马兰戈尼效应模型**
2. **毛细效应与马兰戈尼效应耦合模型**

两个模型采用基本相同的几何结构、材料、物理场接口和初始条件，主要差异包括：

- 固体边界接触角；
- 表面张力系数表达式；
- 网格精细程度。

---

## 2. 模型接口组成

两个模型均包含以下接口：

- 层流 `Laminar Flow (spf)`
- 流体相场 `Phase Field (pf)`
- 稀物质传递 `Transport of Diluted Species (tds)`
- 域常微分和微分代数方程 `Domain ODEs and DAEs (dode)`
- 两相流—相场耦合 `Two-Phase Flow, Phase Field`
- 自由三角形网格
- 相初始化与瞬态研究

---

# 3. 层流接口 `Laminar Flow (spf)`

## 3.1 基本设置

用于求解液相和气相区域中的速度场与压力场。

| 设置项 | 当前设置 |
|---|---|
| 域选择 | 所有域 |
| 流动类型 | 不可压缩流体 |
| 重力 | 启用 |
| 流体离散化 | `P2 + P1` |
| 参考压力水平 | `1 atm` |
| 参考温度 | `T = 150 °C` |
| 静水压力补偿 | 均不启用 |
| 壁面边界条件 | 无滑移 |
| 压力点约束 | 液体区域内部一点，且不位于壁面或气液界面上 |

## 3.2 边界条件

### 内壁

将衬底设置为内壁，同时选择无滑移边界条件。

### 压力点约束

压力点约束位于液体域内部，其作用是为不可压缩流动中的压力场提供参考，避免压力解存在任意常数。

该点必须满足：

- 位于液体区域；
- 不位于固体壁面；
- 不位于气液界面；
- 不与衬底线段重合。

## 3.3 重力设置

二维坐标系中的重力加速度设置为：

```text
g_x = 0
g_y = -g_const
```

# 4. 流体相场接口 `Phase Field (pf)`

## 4.1 接口用途

用于追踪液体和气体之间的自由界面。

模型采用相场变量区分两个流体：

| 相区 | COMSOL 流体编号 | 相场变量 |
|---|---|---:|
| 液体区域 | Fluid 2 | `phi = 1` |
| 气体区域 | Fluid 1 | `phi = -1` |

初始液面位于 `30 mm` 高度处：

- 液面以下为液体；
- 液面以上为气体。

## 4.2 初始液相

初始液相节点选择下部液体域，并设置为：

```text
Fluid 2
phi = 1
```

## 4.3 初始气相

初始气相节点选择上部气体域，并设置为：

```text
Fluid 1
phi = -1
```

## 4.4 润湿壁设置

相场接口包含以下润湿边界：

- Teflon 内壁；
- SiO2 衬底；
- 顶壁。

### 纯马兰戈尼效应模型

为尽量降低接触角差异产生的毛细作用，所有润湿边界均设置为中性接触角：

| 边界 | 接触角 |
|---|---|
| SiO2 衬底 | `90°` |
| Teflon 内壁 | `90°` |
| 顶壁 | `90°` |

### 毛细效应与马兰戈尼效应耦合模型

| 边界 | 接触角 |
|---|---|
| SiO2 衬底 | `theta_SiO2 = 50°` |
| Teflon 内壁 | `theta_teflon = 100°` |
| 顶壁 | `90°` |

上述设置用于表示：

- SiO2 衬底相对亲水；
- Teflon 内壁相对疏水；
- 顶壁采用中性接触角。

## 4.6 相场模型参数

相场模型作用于全部气液计算域，用于描述液相与气相之间的弥散界面。

界面厚度控制参数设置为： epsilon_pf = pf.ep_default

迁移率调整参数采用用户定义形式： chi = 1 m·s/kg

外部自由能对相场变量的导数设置为： ∂f/∂phi = 0 J/m^3


# 5. 稀物质传递接口 `Transport of Diluted Species (tds)`

## 5.1 接口用途

用于描述液体和气体区域中的等效溶质浓度传递。

浓度变量为：

```text
c
本模型中，`c` 表示与氧化镓纳米线生长过程相关的镓离子或等效溶质浓度
```

作用区域：
```text
全部流体域
```

面外厚度：
```text
dz, 1 m
```

传递机制：
```text
对流
溶质随层流接口计算得到的速度场发生迁移，同时包含由扩散系数控制的扩散过程
```

无通量边界：
```text
边界选择：所有 Teflon 壁
溶质不通过对应边界离开计算域
```

衬底通量不连续：
```text
N0,c = k * c
边界选择：衬底
该边界条件用于近似表示衬底表面的镓离子络合、反应或消耗过程。
```

## 5.2 初始浓度

当前初始值节点设置为：

```text
c = c0
因此，在求解初始时刻，所有被稀物质传递接口选中的域都具有数值上定义的浓度变量 `c`
```


采用全域初始浓度的主要数值原因是：

- 气液界面会随时间移动；
- 液体可能进入初始几何划分中的气相域；
- 表面张力表达式在移动界面附近需要调用浓度变量 `c`；
- 若稀物质传递接口只选择初始液相域，则液面移动后可能在原气相域中访问未定义变量 `c`；
- 将稀物质传递接口扩展到全部气液域，可避免移动界面附近出现 `c` 未定义的问题。

需要注意：

全域设置：

```text
c = c0
```

是一种数值定义策略，并不自动表示实际气相中具有与液相完全相同的溶质浓度。

液相与气相之间的物理差异主要通过以下内容进一步区分：

- 相场变量 `phipf`；
- 液相指示变量 `u2`；
- 液相与气相不同的扩散系数；
- 可能使用 `u2` 调节的源项、通量或材料参数。
---

## 5.3 液相与气相的动态区分

由于相场法中的气液界面会随时间移动，不能只依靠最初的几何域编号判断某个位置属于液体还是气体。

为使传质参数能够随气液界面移动而更新，模型通过域常微分和微分代数方程接口定义液相指示变量：

```text
u2
```

该变量根据相场变量 `phipf` 动态判断当前位置是否属于液相。

最终采用的判断条件为：

```text
u2 = (phipf > 0.2)
```

因此：

```text
当 phipf > 0.2 时，u2 = 1
当 phipf <= 0.2 时，u2 = 0
```

其中：

- `u2 = 1` 表示该位置被归类为液相；
- `u2 = 0` 表示该位置被归类为气相或界面外侧区域。

相场变量的典型取值为：

```text
液相主体：phipf ≈ 1
气相主体：phipf ≈ -1
气液界面：phipf 在 -1 至 1 之间连续变化
```

# 6. 域常微分和微分代数方程接口 `Domain ODEs and DAEs (dode)`

## 6.1 作用区域

该接口选择：

```text
所有域
```

## 6.2 状态变量

状态变量定义为：

```text
u2
```

初始值设置为：

```text
u2 = 0
```

## 6.3 方程设置

分布式常微分方程的源项为：

```text
u2 - (phipf > 0.2)
```

阻尼或质量系数为：

```text
da = 0 
ea = 0
```

在当前设置下，该接口主要承担代数约束作用，使：

```text
u2 = (phipf > 0.2)
```

因此预期得到：

```text
当 phipf > 0.2 时：u2 = 1
当 phipf <= 0.2 时：u2 = 0
这里设置的 (phipf > 0.5) 是为了确保液体域确实到达了该区域，理论上 (phipf > 0) 即可，但是不排除气液共存的情况，因此设置为0 - 0.5均可
```

# 7. 两相流—相场多物理场耦合
## 7.1 耦合接口


模型启用：

```text
Two-Phase Flow, Phase Field
```

该接口将：

- 层流 `spf`；
- 流体相场 `pf`

进行耦合，作用域为全部流体域

## 7.2 表面张力设置

模型启用：

- 动量方程中的表面张力；
- 表面张力中的表面张力梯度效应。

表面张力系数采用用户定义表达式。

### 纯马兰戈尼效应模型

表面张力表达式为：

```text
sigma = dsigmadc * (c - c0)
```
该表达式用于突出浓度变化引起的表面张力差异。

### 毛细效应与马兰戈尼效应耦合模型

表面张力表达式为：

```text
sigma = sigma_ref + dsigmadc * (c - c0)
```

## 7.5 两个模型的主要差异

| 设置项 | 纯马兰戈尼效应模型 | 毛细效应 + 马兰戈尼效应模型 |
|---|---|---|
| SiO2 接触角 | `90°` | `50°` |
| Teflon 接触角 | `90°` | `100°` |
| 顶壁接触角 | `90°` | `90°` |
| 表面张力 | `dsigmadc*(c-c0)` | `sigma_ref+dsigmadc*(c-c0)` |
| 基准毛细压力 | 尽量弱化 | 保留 |
| 壁面润湿差异 | 不考虑 | 考虑 |
| 网格 | 相对更精细 | 相对稍粗 |

# 8. 网格设置

### 网格类型

两个模型均使用：

```text
自由三角形网格
```

### 重点加密区域

网格设置重点关注：

- 初始气液界面；
- SiO2 衬底附近；
- 衬底与初始液面交汇区域；
- 润湿边界附近；
- 预计自由液面形变明显的区域。

# 9. 研究步骤
### 模型研究包含两个主要步骤：
1. 相初始化；
2. 瞬态求解。

相初始化用于生成稳定的初始气液界面，并建立相场变量的初始分布。

瞬态研究用于计算自由液面随时间的演化。

### 相关设置
- 容差：物理场控制
- 起始时间：0s
- 结束时间：20s
- 输出时间间隔：1s
- 相对容差：0.01


# 瞬态求解器设置（关键）：

## 1. 常规设置

| 设置项 | 当前设置 | 说明 |
|---|---|---|
| 研究步骤 | 步骤 2：瞬态 | 瞬态求解器由研究中的第二个步骤定义 |
| 时间单位 | `s` | 时间单位为秒 |
| 输出时步 | `range(0,1,20)` | 从 0 s 开始，每隔 1 s 输出一次，终止时间为 20 s |
| 要存储的时步 | 求解器采用的最接近输出时间的步长 | 只保存最接近指定输出时间的内部求解步，避免保存全部内部时步造成过大的内存和磁盘占用 |
| 相对容差 | `0.01` | 控制求解误差的相对容许范围 |

## 3. 时间步进设置

| 设置项 | 当前设置 | 说明 |
|---|---|---|
| 求解器类型 | 隐式 | 使用隐式时间积分，适合刚性较强的多物理场瞬态问题 |
| 时间积分方法 | 向后差分公式 | 使用 BDF 方法进行时间离散 |
| 求解器采用的步长 | 自由 | 求解器根据误差和收敛情况自适应调整内部时间步长 |
| 在结束时间插值解 | 不启用 | 不强制在终止时间通过插值生成解 |
| 初始步长 | `0.001 s` | 求解开始时采用较小的时间步长 |
| 最大步长约束 | 自动 | 最大内部时间步长由求解器自动确定 |
| 最大 BDF 阶次 | `2` | 时间积分最高采用二阶 BDF |
| 最小 BDF 阶次 | `1` | 时间积分最低采用一阶 BDF |
| 事件容差 | `0.05` | 用于事件检测和事件定位的容差 |
| 非线性控制器 | 启用 | 根据非线性收敛情况调整时间步长 |
